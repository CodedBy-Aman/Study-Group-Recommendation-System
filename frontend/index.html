Stable matching + skill complementarity

Gale-Shapley guarantees no two students would mutually prefer to swap groups. Our scoring engine computes how well your skill vectors complement each other — matching your weak areas against others' strengths.

bid_calculator.cpp
// complementarity score formula
double computeBid(
  const Student& a,
  const Student& b
) {
  double score = 0.0;
  for (auto p : a.skills) {
    string topic = p.first;
    double s_a = p.second;
    double s_b = b.skills[topic];
    score += s_a*(1.0-s_b) + s_b*(1.0-s_a);
  }
  return score * availability_overlap(a, b);
}
